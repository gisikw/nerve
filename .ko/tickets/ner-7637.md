# Extremely long messages fail to render, showing empty state instead

When a room contains extremely long messages (e.g., a Knockout toolchain run with verbose output), the message list shows "No messages yet" instead of rendering anything. Likely the markdown renderer or message body component is choking on the payload size and silently failing, causing the entire message list to error out and fall back to the empty state.

Need to investigate: is it a rendering timeout, a DOM size limit, or the markdown parser throwing? May need to truncate/collapse long messages with a "show more" affordance.

**Location:** `MessageList.svelte`, `MessageBody.svelte`, `lib/markdown.ts` — wherever long body text gets processed.
